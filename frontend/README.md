# Frontend

The React client for the Twitter clone. Run commands from this directory, or use
the convenience scripts in the repository root.

## Source layout

- `app/` contains application-wide configuration.
- `components/` contains reusable layout, UI, SVG, and loading components.
- `features/` contains components owned by a product feature.
- `hooks/` contains shared React hooks.
- `layouts/` contains route-independent page shells.
- `pages/` contains route-level components.
- `utils/` contains API and data transformation helpers.

## Commands

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run preview` serves the production build locally.
